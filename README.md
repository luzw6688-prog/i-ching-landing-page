# AI Oracle: I Ching Wisdom Landing Page

An English, conversion-focused landing page for the AI Oracle: I Ching Wisdom app. The site uses native HTML, CSS, and JavaScript with no build step.

## Local preview

```bash
python3 -m http.server 4173
```

Visit `http://localhost:4173`.

## Before launch

- App Store buttons point to the live AI Oracle product page.
- The download QR code points to the live AI Oracle App Store product page.
- Add the final Privacy and Terms URLs.

## Page structure

- Hero message and App Store CTA
- I Ching philosophy
- Real in-app experience screens
- Daily guidance use case
- User reflections
- Final download conversion section
